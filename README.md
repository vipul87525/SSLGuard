#  SSLGuard - SSL/TLS Security Analyzer & Certificate Auditor

SSLGuard is a web-based security tool built using Python (Flask) and JavaScript that analyzes SSL/TLS configurations of websites to identify potential security risks and misconfigurations.

## Features

* 📜 SSL Certificate Analysis (expiry, issuer, validity)
* 🔍 Detection of Weak Ciphers & Deprecated Protocols
* 🔐 HTTPS Validation & Hostname Verification
* ⚠️ Risk Scoring based on identified vulnerabilities
* 📁 Downloadable Security Reports

##  Tech Stack

* Backend: Python (Flask)
* Frontend: HTML, CSS, JavaScript
* Libraries: SSL, Socket

## Installation & Setup

1. Clone the repository:
   git clone https://github.com/your-username/SSLGuard.git

2. Navigate to the project folder:
   cd SSLGuard

3. Install dependencies:
   pip install -r requirements.txt

4. Run the application:
   python app.py

5. Open in browser:
   http://127.0.0.1:5000/

## Usage

* Enter a domain name to analyze SSL/TLS configuration
* View certificate details and detected vulnerabilities
* Check risk level based on security findings
* Download reports for further analysis
